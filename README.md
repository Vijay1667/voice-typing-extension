# Voice Typing in Browsers

Currently this feature is not in browsers by default (just like you would get in a mobile phone). My extension solves this problem. It also supports multiple langauges.

It used manifest v3.

Works perfectly on: Chrome, Edge, Firefox.  Yet to test on Safari.
